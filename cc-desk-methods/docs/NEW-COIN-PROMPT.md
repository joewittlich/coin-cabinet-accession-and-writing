Master: `AGENTS.md` (hidden in Files). Visible twin: `PROJECT-INSTRUCTIONS.md`. After editing either spec, say `sync spec`.

Attach obverse and reverse images, then send:

```
New coin on the desk.

Assign the next CC number from the register Control sheet (not from memory).
Identify from the photos (and this note if any): [optional description, weight, diameter, axis, ticket text].

One lock sentence (Locked / Guessed or unread), then draft the eight-line flip and the Register row, including series (roman / greek / byzantine / medieval / judaean / misc / modern) and title (obverse rank: Caesar / Augustus / Augusta / Divus / Emperor / Empress / King / Ethnarch / Prefect / Class A2… — never blank or ?).
Do not write the spreadsheet until I say to proceed with accession.
```

After you accept the ID:

```
Proceed with accession of CC-00xx.
Write the Register row.
Give me the chat title to apply.
```

After the row is written, optional:

```
Enrich CC-00xx for the companion site.
Draft enrichment/CC-00xx.json.
Do not write the file until I say to proceed with enrichment.
```
